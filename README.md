# Análise de Desempenho de Funcionários - Power BI

<a href="https://app.powerbi.com/groups/me/reports/c5c67b4a-9be2-4ee4-b5bc-28cb0b24c2d9/2c1abfc00200b0580ba1?experience=power-bi" target="_blank" rel="noopener noreferrer">Meu Projeto no PowerBI</a><br><br>

Este projeto de Power BI analisa o desempenho de funcionários em uma empresa fictícia, com foco em identificar padrões, outliers e oportunidades de melhoria.

## Objetivos
- Avaliar o desempenho individual e por departamento
- Identificar relações entre salário, horas extras e desempenho
- Propor ações baseadas em dados para gestão de pessoas

## Dados
Dados fictícios gerados no Power Query incluindo:
- Informações demográficas dos funcionários
- Métricas de desempenho trimestrais
- Salários e cargos

## Principais Funcionalidades
- 3 páginas interativas de dashboard
- Filtros cruzados entre gráficos
- Cálculos avançados com DAX
- Visualizações dinâmicas e interativas

## Técnicas Utilizadas
- Modelagem de dados (relacionamento 1:*)
- Criação de medidas DAX complexas
- Visualizações interativas
- Análise de tendências e padrões

## Como Usar
1. Baixe o arquivo .pbix
2. Abra no Power BI Desktop
3. Explore as interações entre gráficos
4. Utilize os filtros para análises específicas

## Insights Principais
1. O departamento de TI apresenta o melhor desempenho médio
2. Funcionários com 3-5 anos de empresa têm melhor ROI
3. Horas extras acima de 20/semana não correlacionam com melhor desempenho
